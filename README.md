# Воспроизведение CVE-2021-43798 (Grafana)

Лабораторная работа №2 по информационной безопасности. Воспроизведение реальной уязвимости
обхода каталога (directory traversal, CWE-22) в Grafana на изолированном Docker-стенде:
анализ причины, применение исправления и верификация.

## Суть

**CVE-2021-43798** (CVSS 7.5) — обработчик статических файлов плагина в Grafana 8.0.0-beta1 … 8.3.0
подставляет имя файла из URL без очистки `../`, из-за чего неаутентифицированный пользователь может
прочитать произвольные файлы процесса по пути `/public/plugins/<id>/../../…/<файл>`. Исправлено в 8.3.1.

Стенд сравнивает две версии рядом:

- `vulnerable` — Grafana 8.3.0 (`127.0.0.1:18083`);
- `fixed` — Grafana 8.3.1 (`127.0.0.1:18084`).

Атака читает только специально подготовленный файл `fixture.txt` (смонтирован как `/tmp/lab2-proof.txt`),
без реальных секретов. Всё работает только на loopback.

## Как запустить

```bash
docker compose -f compose.yaml up -d
python3 demo.py
```

`verify.py` шлёт одинаковые запросы в оба контейнера и проверяет: уязвимая версия отдаёт файл
(HTTP 200 + маркер), исправленная блокирует (HTTP 404), штатный вход `/login` работает в обеих.
Результат сохраняется в `results.json`.

Остановить стенд:

```bash
docker compose -f compose.yaml down
```

## Содержимое

- `compose.yaml` — стенд (Grafana 8.3.0 + 8.3.1);
- `verify.py` / `demo.py` — проверка уязвимости и сравнение версий;
- `fixture.txt` — учебный файл, читаемый при проверке;
- `build_report.py` / `render_terminal.py` — сборка PDF-отчёта;
- `evidence/` — данные NVD по CVE;
- `screenshots/` — вывод проверки и сравнение HTTP-ответов;
- `output/pdf/` — итоговый отчёт;
- `Для защиты.md` — краткий конспект к защите.

## Стек

Python 3, Docker, Grafana 8.3.0/8.3.1, NVD/CVSS.
